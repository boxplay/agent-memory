# 记忆星云 · Memory Sphere（双星球版）

给自己看的记忆图谱：**工作和日常各是一颗记忆球**，中间由一个"自我/关联桥"连着。
单文件、零依赖、不联网，双击 `index.html` 即开。

## 两颗球的读法

- **左球 = 工作（蓝）**、**右球 = 日常（绿）**，球上方有分类标签
- **球面**：日期节点按时间铺开，作为骨架锚点在表面
- **球内体积**：任务（事件/承诺）均匀分布在整个球体内，由淡色骨架线连向日期，形成分子网结构
- **承诺 / 提醒**：红色节点分布在球体内，未完成的有呼吸脉冲
- **球外一圈**：会话段（蓝）、产物文件（黄）——目前都属于工作球
- **中央桥**：人格（金色）、用户画像（青色）、主题 / 实体（青/粉），
  它们同时连着两颗球的卡片，所以跨球的线会穿过中间
- **跨球连线**：同一天的"工作 ↔ 日常"用淡蓝虚线连起来
- **红色虚线**：更正链（旧认知 → 新认知）

## 交互

| 操作 | 效果 |
|---|---|
| 拖拽某个球 | **只旋转这一颗球**（另一颗保持不动）；在空白处拖动才是两颗一起转 |
| 悬停/选中 | 亮出关联线；选中时放大 2.6×、附近 260px 内任务显示标签 |
| 滚轮缩放 | 只改变节点之间的间距，**节点/高亮环大小固定**（不再越放大越巨大） |
| 滚轮 | 以画面中心缩放 |
| 单击节点 | 该节点所在球 **900ms 缓动放大到 2.6× 并精确居中**；选中节点脉冲双环高亮，关联节点亮环 + 标签，附近 160px 内任务也显示标签；落位后弹出详情 |
| 关闭 / Esc / 点空白 | 详情滑出，镜头回弹到点击前的双球视角 |
| 左侧列表 | **固定显示**，分 时间线 / 承诺 / 主题；点击条目只做**定位**（放大到对应球并居中，不弹详情） |
| 连线 | **静态不画线**；悬停或选中节点时，才亮出它的关联线，避免满屏白线 |
| 顶部搜索 | 按人/事/主题搜索，选中后聚焦 |
| 左下角图例 | 按类型淡出/淡入 |
| 右上角「自转」 | 双球慢速自转，聚焦时自动暂停 |
| 右上角「重置视角」 | 回到双球全局视图 |

快捷键：`/` 聚焦搜索，`Esc` 关闭详情并回弹。

## 背景点缀（纯装饰）

都是屏幕空间的远景，不参与点击、不影响球体交互：

- **远处星系 ×12**：带旋臂与倾斜星系盘，大小/亮度分远近两层，缓慢自转
- **星云 ×6**：缓慢流动，内部有 3 条流动亮丝
- **行星 ×3**：程序贴图 + 自转 + 晨昏线光照（气态巨行星 / 冰行星+环+卫星 / 类地行星），
  比上一版**更小更淡**，只做远景氛围
- **小型宇宙飞船**：5 种船型（箭头战机 / 飞碟 / 巡洋舰 / 三角截击机 / 运输船），从边缘随机穿梭，带极淡的引擎微光，**不拖白色线条**；整体压暗，偶尔出现（约 9–21 秒一艘）
- **恒星视差 / dolly 感**：镜头推进时远景轻微缩放
- **没有球壳**：不画大气层/经纬网；用一层**细小、不发光、不叠加雾化**的球面点云补密度，让记忆点团能读成球（每球 3200 个点，1–2px，普通混合、背面变暗）

`?ships=1` 飞船演示（约 1.5 秒一艘，`?meteors=1` 为旧别名）；`?lite=1` 关闭全部点缀。

## 参数

| 参数 | 作用 |
|---|---|
| `?open=1` | 启动时聚焦工作球的 10-29（演示放大居中） |
| `?ships=1` | 飞船演示模式（`?meteors=1` 为旧别名） |
| `?noanim=1` | 关闭过渡动画（截图用） |
| `?lite=1` | 关闭背景点缀与毛玻璃（低性能机器） |

## 数据

目前是 mock 数据，写在 `index.html` 的 `DAY_DEFS / COMMITMENTS / PROFILES / TOPICS / ENTITIES / SEGMENTS / ARTIFACTS` 里；
每个卡片和承诺带 `cat: 'work' | 'daily'`，决定它落在哪颗球。

接真实记忆时：

1. 写 `build-graph.mjs`，把 `memory/` 下的 markdown 解析成 `graph.json`（节点 + 边 + 分类）
2. 把页面里的 mock 构建换成读 JSON
3. 布局会按 `cat` 自动分球、按类型自动分层；交互与投影层不用改

设计说明见 [`../research/Agent记忆管理方案-分层时间索引-20261029.md`](../research/Agent记忆管理方案-分层时间索引-20261029.md) 第 17 节。
